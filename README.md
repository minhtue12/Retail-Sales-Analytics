# 🛒 Retail Sales Analytics (Supermarket Sales)

## 🎯 Mục tiêu
Phân tích dữ liệu bán lẻ từ 3 chi nhánh siêu thị để hiểu:
- Hiệu suất bán hàng
- Hành vi khách hàng
- Sản phẩm mang lại doanh thu cao nhất
- Xu hướng theo thời gian

## 🧩 Công cụ
- Excel → khám phá sơ bộ
- SQL → làm sạch và tổng hợp dữ liệu
- Python (Pandas + Matplotlib) → EDA & tự động báo cáo
- Power BI → Dashboard trực quan


## 🔍 Insight chính
- Branch C chiếm ~37% doanh thu tổng
- Sản phẩm “Food & Beverage” và “Health & Beauty” là nhóm mạnh nhất
- Doanh thu tăng mạnh vào tháng 2 và 3
- Khách hàng nữ chiếm 55% nhưng chi tiêu trung bình cao hơn 12%
